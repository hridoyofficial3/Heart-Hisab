# হিসাব খাতা (Hisab Khata) 2.0

একটি সাধারণ, দ্রুত ও অফলাইন-ফ্রেন্ডলি ব্যক্তিগত আয়-ব্যয় হিসাবরক্ষণ অ্যাপ। শুধু HTML/CSS/JS দিয়ে তৈরি, কোনো বিল্ড টুল বা সার্ভার লাগে না — সব ডেটা ব্রাউজারের `localStorage`-এ সংরক্ষিত হয়।

**তৈরি করেছেন:** Imran Islam Hridoy

## বৈশিষ্ট্য
- আয়/ব্যয় লেনদেন ট্র্যাকিং, একাধিক অ্যাকাউন্ট (নগদ, ব্যাংক, বিকাশ, সেভিংস)
- সাপ্তাহিক/মাসিক/বাৎসরিক রিপোর্ট ও চার্ট
- PIN দিয়ে অ্যাপ লক (PBKDF2-SHA256 + AES-256-GCM)
- বাংলা ভাষায় সম্পূর্ণ ইন্টারফেস (i18n সাপোর্ট সহ)
- ইনস্টলযোগ্য PWA (হোম স্ক্রিনে যোগ করা যায়)

## চালানোর উপায়
এটি একটি স্ট্যাটিক সাইট — যেকোনো স্ট্যাটিক হোস্টে (GitHub Pages, Netlify, Vercel) ডিপ্লয় করা যায়, অথবা লোকালি:

```bash
# যেকোনো একটি
npx serve .
# অথবা
python3 -m http.server 8080
```

তারপর ব্রাউজারে `index.html` খুলুন।

### GitHub Pages-এ ডিপ্লয়
1. এই রিপোর জন্য Settings → Pages এ যান
2. Branch হিসেবে `main` এবং folder `/ (root)` নির্বাচন করুন
3. Save করুন — কিছুক্ষণ পর সাইটটি লাইভ হয়ে যাবে

## ফাইল স্ট্রাকচার
```
index.html     — মূল মার্কআপ
style.css      — সব স্টাইল
app.js         — অ্যাপ কন্ট্রোলার (init, navigation, lock screen)
store.js       — ডেটা লেয়ার (localStorage)
security.js    — PIN লক ও এনক্রিপশন
ui.js          — UI হেল্পার (toast, modal, theme)
icons.js       — SVG আইকন সেট
i18n.js        — ভাষা/অনুবাদ
manifest.json  — PWA manifest
icon-192.png / icon-512.png / icon-maskable-512.png — অ্যাপ আইকন
```

## নোট
- সব ডেটা শুধু ব্যবহারকারীর ডিভাইসে (localStorage) থাকে — কোনো সার্ভারে পাঠানো হয় না
- অফলাইনে ইনস্টলড PWA হিসেবে পূর্ণ ক্যাশিং দরকার হলে একটি `service-worker.js` যোগ করা যেতে পারে (বর্তমানে অন্তর্ভুক্ত নয়)
