# হিসাব খাতা (Hisab Khata) 2.1

একটি সহজ, দ্রুত ও অফলাইন-ফ্রেন্ডলি ব্যক্তিগত আয়-ব্যয় হিসাবরক্ষণ অ্যাপ। শুধু HTML/CSS/JS — কোনো বিল্ড টুল বা সার্ভার লাগে না। সব ডেটা ব্রাউজারের `localStorage`-এ থাকে।

**তৈরি করেছেন:** Imran Islam Hridoy

## বৈশিষ্ট্য
- আয় / ব্যয় / **ট্রান্সফার** (নগদ → ব্যাংক ইত্যাদি, রিপোর্ট বিকৃত না করে)
- একাধিক অ্যাকাউন্ট ও কাস্টম ক্যাটাগরি (যোগ, এডিট, মোছা)
- সাপ্তাহিক / মাসিক / বাৎসরিক / সার্বিক রিপোর্ট ও চার্ট
- PIN অ্যাপ লক (PBKDF2-SHA256, ক্রমবর্ধমান লকআউট), ব্যাকআপে AES-256-GCM
- বাংলা ও ইংরেজি ইন্টারফেস
- ব্যাকআপ/রিস্টোর (JSON, পাসওয়ার্ডসহ এনক্রিপ্টেড) + CSV এক্সপোর্ট (এক্সেলের জন্য)
- ইনস্টলযোগ্য PWA, সার্ভিস ওয়ার্কারসহ অফলাইনে চলে

## চালানোর উপায়
```bash
npx serve .          # অথবা
python3 -m http.server 8080
```
তারপর ব্রাউজারে `http://localhost:8080` খুলুন। (সার্ভিস ওয়ার্কার ও এনক্রিপশনের জন্য `file://` নয়, http/https লাগবে।) GitHub Pages / Netlify / Vercel-এও ডিপ্লয় করা যায়।

## ফাইল স্ট্রাকচার
```
index.html   — মূল মার্কআপ
style.css    — সব স্টাইল
app.js       — অ্যাপ কন্ট্রোলার (init, লক স্ক্রিন, মডাল, ব্যাকআপ)
store.js     — ডেটা লেয়ার (localStorage, ভ্যালিডেশন, ইম্পোর্ট/এক্সপোর্ট)
security.js  — PIN লক ও এনক্রিপশন
ui.js        — রেন্ডারিং (হোম, লেনদেন, রিপোর্ট, সেটিংস)
i18n.js      — বাংলা/ইংরেজি অনুবাদ
icons.js     — SVG আইকন
sw.js        — সার্ভিস ওয়ার্কার (অফলাইন ক্যাশ)
manifest.json, icon-*.png — PWA
```

## নিরাপত্তা সম্পর্কে সৎ কথা
- PIN লক একটি **অ্যাপ-স্তরের** সুরক্ষা: ফোন/ল্যাপটপে অন্য কেউ অ্যাপ খুললে দেখতে পারবে না। কিন্তু `localStorage`-এর ডেটা এনক্রিপ্টেড নয়, তাই ব্রাউজারের DevTools বা ডিভাইসে সরাসরি ফাইল-অ্যাক্সেস থাকলে ডেটা পড়া সম্ভব।
- AES-256-GCM শুধু **পাসওয়ার্ড-সহ ব্যাকআপ ফাইলে** প্রযোজ্য।
- "PIN ভুলে গেছেন?" চাপলে লক বন্ধ করার জন্য **সব ডেটা মুছে যায়** — তাই নিয়মিত ব্যাকআপ নিন।

## 3.0 — প্রিমিয়াম ডিজাইন
নতুন গাঢ় পান্না-সবুজ ও শ্যাম্পেন-গোল্ড থিম, গ্লাস নেভিগেশন, নতুন লক স্ক্রিন, রিফাইন্ড কার্ড, চার্ট, ফর্ম ও মডাল (লজিক অপরিবর্তিত)।

## 2.1-এ কী ঠিক হয়েছে
- **লক বাইপাস:** "PIN ভুলে গেছেন?" আগে ডেটা না মুছেই লক খুলে দিত; এখন সত্যিই ডেটা মোছে। এছাড়া এই ডায়ালগ লক স্ক্রিনের নিচে লুকিয়ে থাকত (z-index) — এখন ঠিকমতো দেখা যায়।
- **রিপোর্ট ট্যাব:** সপ্তাহ/বছর/সব ট্যাব আসলে কাজ করত না (সবসময় "মাস" দেখাত)।
- **ভাষা:** ইংরেজি বেছে নিলে এখন পুরো অ্যাপ ইংরেজি হয় (আগে অর্ধেক বাংলা থাকত)।
- **এডিট:** আয়/ব্যয় টাইপ বদলালে এখন সত্যিই সেভ হয়; আর্কাইভ করা অ্যাকাউন্টের লেনদেন এডিটে অ্যাকাউন্ট চুপচাপ বদলে যেত — ঠিক হয়েছে।
- **ট্রান্সফার** ফিচার যোগ; ক্যাটাগরি এডিট; আর্কাইভ অ্যাকাউন্টের ব্যালেন্স হোমে দেখানো (যোগফল মেলে)।
- **ইম্পোর্ট:** কঠোর ভ্যালিডেশন (টাইপ, তারিখ, ডুপ্লিকেট আইডি, হারানো অ্যাকাউন্ট), সেটিংস স্যানিটাইজ, রিস্টোরের আগে স্বয়ংক্রিয় সেফটি-ব্যাকআপ।
- **ব্রুট-ফোর্স:** লকআউট প্রতিবার দ্বিগুণ (৩০ সেকেন্ড → সর্বোচ্চ ১ ঘণ্টা), লাইভ কাউন্টডাউন; ইনঅ্যাক্টিভ লকে খোলা মডাল বন্ধ হয়।
- বাংলা ডিজিটে পরিমাণ লেখা (১২৩), সার্চে পরিমাণ/অ্যাকাউন্ট/তারিখ, লম্বা তালিকায় "আরও দেখুন", PIN প্যাডের লেআউট, কীবোর্ড সাপোর্ট।
- সার্ভিস ওয়ার্কার (সত্যিকারের অফলাইন), ডেমো কোড অপসারণ, সংস্করণ নম্বর এক জায়গায়।

## GitHub দিয়ে অ্যাপ বানানো

### পথ ১ — PWA → APK (PWABuilder)
1. সব ফাইল GitHub রিপোর **রুটে** আপলোড করুন।
2. Settings → Pages → Branch: `main` / root → Save।
3. লিংক (`https://ইউজারনেম.github.io/রিপো/`) pwabuilder.com-এ দিন → Package for stores → Android → ডাউনলোড।

### পথ ২ — Capacitor + GitHub Actions (অফলাইন, পুরো অ্যাপ APK-র ভেতরে)
1. `main` ব্রাঞ্চে পুশ করুন (`.github/workflows/build-apk.yml` নিজে চলবে)।
2. রিপোর **Actions** ট্যাব → সর্বশেষ "Build APK" রান → নিচে **Artifacts** থেকে `hisab-khata-apk` নামান।
3. জিপ খুলে `app-debug.apk` ফোনে ইনস্টল করুন (অজানা উৎস থেকে ইনস্টল চালু করতে হবে)।

প্রয়োজনে Actions ট্যাব থেকে "Run workflow" চেপেও বিল্ড করা যায়।
